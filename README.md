Ocula is a free photo browser for 64-bit Windows 10 and 11 that shows your folders, thumbnails and the
selected photo side by side, in light or dark mode.

## Features

- **Every common format**, including RAW files from Canon (CR2, CR3), Nikon, Sony, Fujifilm and
  more, plus HEIC, AVIF and WebP. RAW+JPEG pairs show as one photo.
- **Ratings, colour labels and tags** saved in the files themselves (or in standard `.xmp`
  sidecars for RAW), so Lightroom, Bridge and File Explorer see them too.
- **HDR detection** for gain-map photos (Ultra HDR, iPhone), PQ/HLG images and HDR merges.
- **Camera details**, with a photo of the camera that took each picture.
- **Fast culling**: sharpness scores flag blurry shots, bursts collapse into stacks, and
  compare view shows 2 or 4 photos with linked zoom, with pick/reject flags (P / X).
- **Card import** with renaming, tags and a simultaneous NAS backup; batch rename;
  "Edit in" Lightroom, Photoshop, Capture One and others; PDF contact sheets; and client
  proofing galleries where clients heart their favourites.
- **Video playback** for MP4, MOV, MKV, WebM, AVI and more, with audio-track and subtitle menus.
- **Slideshows and a second-screen view** for showing clients photos on a TV.
- **Accurate colour** for Display P3 and Adobe RGB photos, and **true HDR** on HDR screens.
- **Timeline, collections and smart albums** that organise without moving files.
- **Quick edits**: crop, straighten, rotate, exposure, contrast, highlights, shadows, warmth and
  saturation, saved as a copy so originals stay untouched.
- **Full-screen viewer** with smooth zoom and a filmstrip.
- **Duplicate finder** that spots exact copies and similar shots, and moves extras to the
  Recycle Bin.
- **Batch export** with presets for the web, social media and archiving, with resizing,
  watermarks and location removal.
- **Fits into Windows**: "Open in Ocula" on folders, Open with, Share, and OneDrive
  online-only files handled without downloading them.

## Install

Install Ocula from the [Microsoft Store](https://apps.microsoft.com/detail/PRODUCT_ID), or with:

```
winget install --source msstore Ocula
```

Store installs are signed by Microsoft and update automatically.
