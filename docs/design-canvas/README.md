Design canvas boards (`*.dc.html`, `canvas.json`) behind the PNGs in `../mockups`.

"3 + 2", "2 + 3" and "Cascade". Superseded on that point: the owner decided on **6 fixed spots** by default,
and the build uses that (see "Photo windows with snap spots" in `BUILDING.md`).
